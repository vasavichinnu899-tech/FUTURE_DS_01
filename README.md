# Sales Analytics Dashboard (Java + Python Implementation)

## Project Overview

This project is a Sales Analytics System built in **two different programming approaches: Java and Python**. Both versions analyze a dataset of sales records and generate business insights such as revenue, top products, top customers, and region-wise performance.

The goal of this project is to demonstrate how the same problem can be solved using different programming languages and data handling techniques.

---

## Project Versions

### 1. Java Version
- Built using Java (OOP + Data Structures)
- Uses:
  - ArrayList
  - HashMap
  - File Handling
- Reads data from `sales.txt`
- Performs analytics using manual logic and DSA concepts

### 2. Python Version
- Built using Python (Pandas-based approach)
- Uses:
  - Pandas
  - DataFrame operations
  - Built-in aggregation functions
- Faster data analysis with minimal code

---

## Features (Both Versions)

- Load sales dataset
- Calculate total revenue
- Identify top product
- Identify top customer
- Region-wise analysis
- Monthly trend analysis
- Data visualization (Python version supports charts)
- Clean structured output
